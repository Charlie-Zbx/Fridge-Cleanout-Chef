- `egg_container`与`overlapping_views`：本批未执行。

宽视角照片原始输出还有实质错误：声称关闭蛋盒里“可见8个鸡蛋”。这不是图片可支持的数量；虽然obscured=true使程序不填库存数量，观察本身仍需修正。不能因为格式兼容成功就把它算作识别正确。

## 离线修复

新增严格限定的解析兼容：只忽略顶层值为`json_object`或`object`的多余type标记，保留解析提示记录。未知动作、其他额外字段、非法数量、单位及食材字段继续严格拒绝；不进行模型自动重试。

已使用保存的失败响应，通过MockTransport离线回放全部解析和数量规则，得到15条待确认观察、全部建议数量为空。16项视觉相关测试通过。此回放没有上传照片、没有真实模型调用，不把首次失败记录改写为首次成功。
