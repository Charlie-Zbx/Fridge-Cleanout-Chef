# 首次真实 Agent 测试

日期：2026-11-08（Asia/Shanghai）。模型：DeepSeek 官方 `deepseek-flash`，非思考模式。用户分别明确批准单次连通测试和一次 Agent 示例任务；没有执行其他真实测试或图片上传。

## 输入与执行

库存为鸡蛋 3 个、卷心菜 200 g、豆腐 300 g；常备油和盐。一人、两顿、每顿最多 20 分钟、只有平底锅、优先用卷心菜。本次允许未审核的开发配方，不表示配方已经实做。

LangChain 主 Agent 通过真实 stdio MCP 发现三个工具，执行一次 search_recipes、三次 get_recipe、三次 evaluate_plan。

1. 初稿：第一顿卷心菜炒蛋，第二顿清炒卷心菜和香煎豆腐。程序发现卷心菜需要 250 g、库存只有 200 g；第二顿顺序制作约 30 分钟，超过 20 分钟。
2. 第一次调整：第二顿只保留清炒卷心菜。工具仍发现卷心菜超库存 50 g。
3. 第二次调整：第二顿改为香煎豆腐。MCP 检查通过，宿主最终独立检查也通过。

最终第一顿卷心菜炒蛋，预计 15 分钟；第二顿香煎豆腐，预计 18 分钟。预计剩余鸡蛋 1 个、卷心菜 100 g、豆腐 150 g。时间来自未实做的示例配方，并非真实烹饪测量。测试只计算库存，没有写入用户厨房或扣减真实库存。
